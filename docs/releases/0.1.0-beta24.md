# PXE Tools 0.1.0 bêta 24

- Dans **Images PXE → Ajouter une image**, chaque distribution dispose de
  son onglet. Les cases cochées restent sélectionnées quand on change d’onglet.
- Lorsque les onglets débordent, deux chevrons permettent de les faire
  défiler. Les onglets sont également accessibles au clavier.
- Le tableau des médias d’installation présente des lignes de même hauteur.
  Le visuel Windows 11 est aligné à gauche et Proxmox utilise le logo orange
  et noir d’origine.
