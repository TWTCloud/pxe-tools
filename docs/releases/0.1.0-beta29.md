# PXE Tools 0.1.0 bêta 29

- Rust sert directement la console, l’API et les fichiers PXE en HTTP et
  HTTPS. Le paquet APT et l’image Docker fonctionnent sans PHP-FPM ni Nginx.
- Les nouveaux menus et chargeurs utilisent des URL de démarrage dédiées.
  Les anciennes URL restent compatibles après la mise à niveau.
- Le paquet retire les anciennes unités propres à PXE Tools. Il conserve la
  base SQLite, la clé maître et les certificats.
- L’assistant de configuration accepte le lien d’installation prérempli.
  Le port HTTPS de la console est réglable depuis les paramètres.
- Le socle est disponible pour amd64 et arm64, avec le module APT Ansible
  facultatif.
