# PXE Tools 0.1.0 bêta 32

- Windows, Proxmox VE et Red Hat disposent chacun d’un onglet dans Images PXE.
- Le menu Images PXE utilise une icône de disque optique.
- La console indique le motif d’un blocage et identifie l’image Debian protégée pour le secours.

Le socle est disponible en APT et Docker, pour amd64 et ARM64. Le module Ansible APT reste facultatif.
