# PXE Tools 0.1.0 bêta 9 — préparation

Cette version candidate rassemble les corrections d'installation et de
désinstallation natives fusionnées après la bêta 8. Ce document décrit le
périmètre préparé ; il ne constitue pas une preuve de publication APT ni de
réception de la version sur une machine physique.

## Corrections

- Les journaux des services natifs sont placés dans le répertoire d'exécution
  protégé de PXE Tools. Une première installation ne dépend plus de l'absence
  d'écriture par le groupe sur `/var/log` ; les anciens journaux non attestés
  restent conservés.
- Lors d'une configuration APT relancée, une initialisation interrompue peut
  reprendre lorsque le journal et les preuves de création sont suffisants.
  Les preuves insuffisantes et les états ambigus restent bloquants et
  préservés ; la reprise ne revendique pas de données préexistantes.
- Le désinstallateur peut proposer la purge d'une première installation
  interrompue lorsque les chemins restants possèdent des preuves fortes. Il
  conserve les comptes Ansible existants, les journaux non attestés et les
  autres ressources qu'il ne peut attribuer avec certitude. Une interruption
  avant la purge d'un paquet partiellement configuré demande une inspection.
- Les caches Python reconnus sont nettoyés avant la purge lorsque leur
  environnement est sûr. Les fichiers inconnus sont conservés.

## Fonctionnement prévu

Le paquet `pxe-tools` installe le socle natif : console, worker et composants
PXE. L'administration démarre après une première installation réussie ; le
réseau PXE reste désactivé jusqu'à sa configuration et son activation
explicites. En mode proxy DHCP, le DHCP existant continue d'attribuer les
adresses. Le paquet `pxe-tools-ansible` reste facultatif et n'est pas une
dépendance du socle.
