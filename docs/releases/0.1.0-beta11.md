# PXE Tools 0.1.0 bêta 11

## Installations Debian

- Le nom du compte technique des prochaines installations se règle dans
  **Paramètres → Ansible**. La valeur par défaut est `ansible`. Le serveur
  vérifie le nom et interdit de réutiliser le compte administrateur du
  modèle. Le preseed et le worker utilisent le compte choisi. [PR #88](https://github.com/williamboglietti/pxe-tools/pull/88)
- Le système installé signale son premier démarrage à PXE Tools et réessaie
  si le réseau est indisponible. Le serveur confirme l'enregistrement du
  signal. Le worker peut alors lancer Ansible même si Debian démarre
  directement sur le disque. [PR #91](https://github.com/williamboglietti/pxe-tools/pull/91)

## Assistant de configuration

Le sélecteur de distributions indique les onglets hors écran et garde l'onglet
actif visible. Les boutons de navigation restent accessibles sur mobile.
L'assistant signale les conflits sur le port HTTP de démarrage.
[PR #89](https://github.com/williamboglietti/pxe-tools/pull/89)

## Distribution APT

`pxe-tools` fournit le socle Debian 13 amd64. `pxe-tools-ansible` est un
module facultatif. Le manifeste APT associe chaque paquet publié à son
commit source, à son build CI et à son empreinte SHA-256.
