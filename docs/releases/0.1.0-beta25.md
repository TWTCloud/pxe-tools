# PXE Tools 0.1.0 bêta 25

- Dans **Certificats TLS**, configurez une autorité ACME privée avec le nom
  DNS de l’instance, l’URL de l’autorité et son certificat racine PEM.
- La console indique l’état de la demande et l’expiration. PXE Tools
  renouvelle et active le certificat sans redémarrage. L’autorité valide
  le nom DNS via HTTP-01 sur le port 80.
- La rubrique **Inventaire** utilise `/admin/inventaire`, y compris dans le
  lien affiché après la découverte PXE. Les anciens liens redirigent vers
  la nouvelle adresse en conservant leurs filtres.
- La distribution APT comprend le socle pour amd64 et ARM64 ainsi que le module
  Ansible facultatif. L’image Docker est disponible pour les deux architectures.
