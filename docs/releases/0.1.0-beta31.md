# PXE Tools 0.1.0 bêta 31

- Le catalogue regroupe les images par série et affiche leur nom de code et leur canal. Le libellé **Latest** indique la version stable la plus récente proposée par chaque distribution.
- Debian propose les versions intermédiaires archivées de Debian 12 et 13 ainsi que l’image hebdomadaire de Debian 14 Forky (**Testing**). L’image de service de l’assistant reste une image Debian stable.
- Ubuntu Server détecte ses images amd64 et ARM64 séparément auprès de l’éditeur et affiche aussi les versions archivées.
- Fedora Server, CentOS Stream, AlmaLinux et Rocky Linux détectent les séries et les architectures proposées par leurs dépôts d’installation.
- L’actualisation affiche son avancement puis met à jour les tableaux du catalogue.

Le socle est distribué en APT et Docker pour amd64 et ARM64. Le paquet APT `pxe-tools-ansible` reste facultatif.
