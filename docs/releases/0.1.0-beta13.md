# PXE Tools 0.1.0 bêta 13

La console, l’API et les fichiers de démarrage sont servis en HTTP et HTTPS
par le binaire Rust. Les distributions APT et Docker sont disponibles pour
Linux amd64 et ARM64. Le paquet `pxe-tools-ansible` reste facultatif.

- Debian confirme le premier démarrage avant de clôturer l’installation.
- La console prépare les installations Ubuntu Server et RHEL 9. Elle peut
  importer le DVD RHEL ou une image Windows depuis un fichier ou une URL
  HTTPS autorisée, vérifier le SHA-256 et mettre le résultat en cache.
- Les éditions Windows peuvent partager un fichier `install.wim` ou
  `install.esd`. La préparation du kit WinPE utilise l’ADK Microsoft.
- La console propose le certificat auto-signé de l’instance, l’import d’un
  certificat externe et la gestion ACME.

Sur une instance neuve, ouvrez `https://127.0.0.1/admin/` depuis le serveur ou
par un tunnel SSH. Le code de configuration figure dans
`/run/pxe-tools-rust-guided/setup-code`. Pour Docker, consultez ce fichier
dans le conteneur avec `docker exec`. Le réseau PXE s’active après la
configuration de l’interface et la confirmation dans l’assistant.

Avant une mise à niveau, sauvegardez ensemble la base SQLite, la clé maître
et les fichiers persistants. Sur APT, arrêtez le worker avant une mise à
niveau du module Ansible. Sur Docker, conservez les volumes existants et
ajoutez le volume TLS décrit dans le fichier Compose. La console Rust
utilise le compte local enregistré dans SQLite.
