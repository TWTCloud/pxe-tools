# PXE Tools 0.1.0 bêta 14

La console HTTPS et l’assistant sont accessibles sur les IPv4 privées
actives du serveur dès le premier démarrage. Depuis un poste du réseau,
ouvrir `https://<IPv4-du-serveur>/admin/`. Le code de configuration
reste accessible à root dans `/run/pxe-tools-rust-guided/setup-code`.
Pour Docker, lire le fichier depuis le conteneur.

Le certificat auto-signé créé pour une nouvelle instance contient les
adresses détectées. Une mise à niveau conserve le certificat existant.
Si ce certificat ne couvre pas l’adresse utilisée, la console permet
d’importer un certificat adapté.

`PXE_ADMIN_BIND` permet de sélectionner une seule IPv4 privée
d’administration. Le serveur garde la boucle locale pour le worker et
l’adresse configurée pour le PXE. La détection des adresses est effectuée
au démarrage du service.

Les distributions sont disponibles en APT et Docker pour Linux amd64
et ARM64. Le module Ansible reste facultatif.
