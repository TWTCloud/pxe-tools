# PXE Tools 0.1.0 bêta 19

- L’assistant prépare Debian stable pour la découverte et le dépannage et
  permet de sélectionner plusieurs images Debian et Ubuntu Server à installer.
- Le catalogue affiche son chargement et une action de relance si nécessaire.
  La console et l’assistant affichent la progression des images en direct.
- La validation est disponible dès que le média de service est prêt. Les
  images facultatives continuent à se préparer en arrière-plan.
