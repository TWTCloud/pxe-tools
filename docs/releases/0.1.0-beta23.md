# PXE Tools 0.1.0 bêta 23

- Dans **Images PXE → Ajouter une image**, le catalogue présente chaque version
  dans une ligne avec des colonnes Intel / AMD (amd64) et ARM64.
- Les cases à cocher permettent de télécharger plusieurs images en une fois.
  Le bouton indique le nombre d’images sélectionnées et reste visible pendant
  le défilement.
- Le tableau des médias d’installation regroupe les actions de téléchargement,
  de préparation et d’import pour Proxmox VE, Red Hat et Windows.
