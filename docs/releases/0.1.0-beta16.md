# PXE Tools 0.1.0 bêta 16

Dans l’assistant, un seul formulaire crée le compte administrateur et prépare
le stockage SQLite. Saisissez une seule fois le code affiché par
`sudo pxe-tools setup`.

Le nouveau code comprend 12 caractères répartis en trois groupes de quatre.
Les majuscules, les minuscules, les espaces et les tirets sont acceptés.
Si SQLite est déjà initialisée et que le compte reste à créer, l’assistant
reprend directement au formulaire du compte.
