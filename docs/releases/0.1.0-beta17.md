# PXE Tools 0.1.0 bêta 17

- Rétablit la modification de l’interface et des sous-réseaux PXE après
  l’assistant, ainsi que le choix entre DHCP externe, proxy DHCP et console seule.
- Rétablit la vue d’ensemble du serveur, avec le réseau PXE, l’inventaire,
  les images téléchargées et les actions en cours.
- Permet de dupliquer les modèles existants et de modifier leurs paramètres de
  localisation, leur serveur NTP, leur miroir Debian et leurs paquets.
