# PXE Tools 0.1.0 bêta 27

- La console accepte le nom du serveur et les noms issus de sa configuration
  DNS locale. Un nom local reconnu permet d’ouvrir la console et de se
  connecter depuis la même adresse.
- Un nom DNS inscrit dans le certificat actif est aussi reconnu par la console.
- Le certificat créé lors d’une installation neuve inclut les noms locaux
  détectés. Lors d’une mise à niveau, PXE Tools conserve le certificat
  existant. Si celui-ci doit couvrir un nouveau nom, importez un certificat
  adapté ou utilisez ACME depuis **Certificats TLS**.
- Le dépôt APT distribue le socle pour amd64 et ARM64 ainsi que le module
  Ansible facultatif.
