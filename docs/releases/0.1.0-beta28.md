# PXE Tools 0.1.0 bêta 28

- PXE Tools vérifie au démarrage quelle IPv4 est attribuée à l’interface
  sélectionnée. Si l’ancienne adresse a disparu, il accepte une adresse de
  remplacement unique sur le même réseau et dans la portée du proxy DHCP.
- Les chargeurs et les menus sont régénérés avant que le service annonce
  la nouvelle adresse aux clients. Sur Ubuntu 24.04 et Zorin OS 18, cette
  étape utilise le même trousseau Debian que le worker.
- Si l’adresse est absente ou ambiguë, la console reste disponible et
  indique que le démarrage PXE est suspendu.
- Le dépôt APT fournit le socle pour amd64 et ARM64, avec le module Ansible
  facultatif.
