# PXE Tools 0.1.0 bêta 15

Cette version APT pour Debian 13 amd64 et arm64 intègre la nouvelle console et
l’assistant de configuration. Le module Ansible reste facultatif.

- La console et l’assistant s’adaptent aux écrans mobiles.
- `sudo pxe-tools setup` affiche le lien HTTPS et le code sur le serveur tant
  que le premier compte administrateur reste à créer.
- Dans l’assistant, les étapes SQLite et de création du compte indiquent
  comment récupérer le code et proposent un bouton pour copier la commande.
- La console prend en charge plusieurs comptes, la gestion des droits et la
  création, la rotation et la révocation des jetons d’API.

Pour mettre à niveau une installation APT existante, actualisez l’index puis
mettez à niveau PXE Tools.

```sh
sudo apt update
sudo apt install --only-upgrade pxe-tools
```
