# PXE Tools 0.1.0 bêta 22

- Le catalogue d’images PXE permet de cocher les versions et architectures
  amd64 et ARM64 disponibles, puis de télécharger la sélection en une fois.
- Les cartes Windows 11 et Red Hat Enterprise Linux affichent les visuels
  officiels, servis par la console.
- La mise à jour depuis la console suit la vérification, le téléchargement
  et l’installation. L’outil récupère les paquets depuis le dépôt signé de
  PXE Tools et résout leurs dépendances avec les sources APT du système.
- Le socle APT reste disponible sur amd64 et ARM64 avec le module Ansible
  facultatif.
