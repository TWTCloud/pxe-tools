# PXE Tools 0.1.0 bêta 8

Cette version réunit le correctif du nginx natif (#61/#63) et la désinstallation APT explicite (#62/#64). Une mise à niveau APT ne déclenche aucune désinstallation.

## Comportement livré

Le paquet désactive le nginx générique installé comme dépendance seulement quand sa provenance, sa configuration stock et son état sont prouvés. Le HTTP dédié peut alors utiliser le port80. Les nginx préexistants, partagés, personnalisés ou dont l'origine est ambiguë sont conservés avec un diagnostic.

Le désinstallateur fournit un aperçu, demande un consentement explicite puis arrête en sécurité les services dédiés lorsqu'aucun travail PXE/Ansible n'est en cours. Il retire les paquets et les ressources dont la création et l'usage exclusif sont établis. Les dépendances, comptes humains, ressources tierces, montages et sauvegardes externes sont préservés. Les sources et clés APT ne sont retirées que si leurs témoins et leur usage le permettent.

Un journal privé durable permet la **reprise explicite** avec `--resume` après interruption, y compris après disparition des helpers du paquet. Une purge dpkg partielle ou une identité modifiée entraîne un diagnostic et une inspection avant de poursuivre ; aucune suppression automatique ne démarre au reboot.

Les installations anciennes sans preuves de création ne sont pas revendiquées rétroactivement. Le script peut conserver leurs données ou ressources ambiguës et le signale ; ne pas interpréter ce résultat comme une suppression complète.

## Commandes

Pour mettre à niveau le socle et le module s'il est déjà installé :

```sh
sudo apt update
sudo apt install --only-upgrade pxe-tools pxe-tools-ansible
```

Pour retirer une installation APT, conserver d'abord une sauvegarde externe vérifiée de la base, des données et des clés. Télécharger et lire l'aperçu :

```sh
curl -fsSLo pxe-tools-uninstall.py https://raw.githubusercontent.com/williamboglietti/pxe-tools/main/packaging/native/uninstall-apt.py &&
sudo python3 ./pxe-tools-uninstall.py --dry-run
```

Après vérification du périmètre, la commande suivante autorise la suppression irréversible des ressources reconnues :

```sh
sudo python3 ./pxe-tools-uninstall.py --yes
```

Uniquement après une interruption d'une suppression déjà autorisée :

```sh
sudo python3 ./pxe-tools-uninstall.py --resume
```

La [FAQ française](https://www.pxetools.com/fr/installation/apt/#faq) et son [équivalent anglais](https://www.pxetools.com/en/installation/apt/#faq) sont coordonnés avec ces mêmes commandes. Le parcours Docker reste distinct.
