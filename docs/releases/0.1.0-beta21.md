# PXE Tools 0.1.0 bêta 21

- Proxmox VE 9.2 se télécharge et se prépare directement depuis le catalogue des
  images. L’installation automatique depuis l’ISO officielle a été validée
  jusqu’au premier démarrage UEFI sur amd64. Sur ARM64, la préparation de
  l’ISO a été validée et le premier démarrage reste à qualifier.
- CentOS Stream, Fedora Server, AlmaLinux et Rocky Linux reviennent dans
  le choix des images et disposent d’un parcours Kickstart ciblé.
- RHEL 9.9 et 9.8 peuvent être téléchargés depuis Red Hat avec un jeton API.
  La console explique comment obtenir le jeton et affiche l’avancement.
- Le menu de compte regroupe le profil, les jetons personnels et la déconnexion.
- Le désinstallateur reconnaît les unités systemd de la variante Rust.
